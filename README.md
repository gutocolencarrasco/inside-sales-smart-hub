# Inside Sales Smart Hub V13

V13 consolidates the operating model into one **Executive Sales Dashboard** with one owner filter and four commercial queues.

## What changed
- Single dashboard filter: **All | Ana | Bruno | Carla | Filipe**.
- Four execution queues: **Workflow | FUP | Negotiation | Growth**.
- Workflow only includes **Identify / Develop**, with Cross Sell / Up Sell and Generate Proposal.
- FUP actions exist only in the FUP queue.
- Negotiation contains proposal revisions for customers requesting price / volume / scope changes.
- Growth is always executed by **Filipe**, with a target rhythm of **30–50 proactive actions/day**.
- Growth signals do **not** inflate Salesforce pipeline; an OPP is created only after customer interaction / interest.
- Filipe owns governed **Normal OPPs up to R$10K**, including their Follow UP.
- Salesforce stage order is standardized everywhere: **Identify → Develop → Propose → Order Promised → Win Closed → Lost Closed**.
- Version number is permanently visible in the sidebar.
- Executive visuals redesigned with multiple chart models and a single management narrative.
- Proposal PDF keeps optional Cross Sell / Up Sell as an **OPTIONAL** line and does not show list price, discount, margin or COGS.

## Demo governance
All names, customers, values, products and scenarios are fictitious and anonymized for demonstration only.
